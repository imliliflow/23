# MELEE — Ювелирный Дом

Веб-каталог ювелирных изделий из драгоценных металлов и камней с фильтрацией, корзиной и отзывами[cite: 1].

## Опубликованный сайт
https://imliliflow.github.io/23/

## Страницы и возможности
- `index.html` — главная страница сайта с навигацией, смысловыми разделами и подвалом[cite: 1, 2].
- `catalog.html` — вторая страница каталога с переходами между страницами и общим оформлением[cite: 1, 2].

## Технологии
- HTML5, CSS3 (адаптивная верстка, медиазапросы, состояния наведения и фокуса), JavaScript[cite: 1, 2].

## История изменений по веткам
- `feature/second-page` — добавлена вторая страница сайта и настроена навигация[cite: 2, 7].
- `feature/responsive` — выполнена адаптация макета и навигации под мобильные экраны.

## Как открыть локально
Откройте файл `index.html` в любом браузере[cite: 1, 2].
